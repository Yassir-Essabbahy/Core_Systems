📁 **[View on Portfolio](https://yessirdev.vercel.app)**

---

## 🔍 Features

* **Physics-Based Floating Hold**: Raycast pickup lifting Rigidbody items to a smooth floating hold position in front of the player camera with collision dampening.
* **Full 3D Inspection Mode**:
  * Free 360-degree item rotation on both X and Y axes via mouse drag.
  * Camera depth-of-field blur focusing on the inspected object.
  * Inspectable metadata display (item name, lore description, interactive examine prompts like turning keys or reading labels).
* **Throw & Placement Physics**:
  * Tuned throw impulse velocity for tossing items.
  * Precision socket placement for keys, fuses, and puzzle artifacts.
